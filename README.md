# 🧮 Math Quiz

A Python math quiz for practicing basic arithmetic in the terminal.

## How it works

- Generates 10 random questions.
- Includes addition, subtraction, multiplication, and division.
- Displays your total correct answers at the end.
- Requires at least 7 correct answers to pass.

## How to run

Make sure Python is installed. From the project folder, run:

```bash
python quiz.py
```

## What I practiced

- Conditional statements with `if`, `elif`, and `else`
- Loops with `while`
- User input with `input`
- Random number generation with `random`
